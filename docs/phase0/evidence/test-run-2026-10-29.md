## Checks that the tests can fail (mutation checks)

A test that can't fail proves nothing, so each suite was deliberately broken once:

- **Scoring fixtures:** changing one expected score (50 → 51) made the TypeScript run fail with `dailyScore: expected 51, got 50`. Restored.
- **Firestore rules:** replacing the rules with "allow everything" made **10 of 14** tests fail. The 4 that still passed check allowed actions. Restored.
- **Supabase RLS:** turning off RLS on `log_events` made the run fail at `FAIL: bob can see alice rows`. Restored.
